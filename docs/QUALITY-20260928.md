## 掃譜與五大功能

- 掃譜：PNG優先、保留較高解析度、逐頁獨立掃描、原圖對照、細節區塊、譜面結構和小節時值檢查、不確定音標記。固定SVG排版支援音符、高低八度、附點、减時線、連弓、指法、弓法及上方小音。原圖仅留於當次頁面，不隨譜面保存。
- 新掃譜後端：`scanErhuScoreV2` 使用 high detail 圖像與嚴格 JSON schema，逐項覆核、不自行補音、限制輸入大小，登入驗證與每日限額。預設 `gpt-4.1` 可由 `ERHU_VISION_MODEL` 設定。
- AI助教：`askErhuTutorV2` 專注可做步驟，不宣稱看過未提供的音/影片，不編造曲譜與資源連結。預設 `gpt-4.1-mini` 可設定 `ERHU_TEXT_MODEL`。V2目前不具資源搜尋，不能聲稱找到新資源；既有助教端點可在標準 build 保留。
- 練習規劃：V2結構化步驟，程式分配整數分鐘，總和一定等於選定時間。舊端點未提供結構時，明示改用系統時間表；舊歷史計畫要求重新生成。
- 跟譜：修復開始/取消/失敗流程；休止、延音不再漏拍，未識別音禁止評分。未改動既有音準閾值與八度容錯策略；研究正式使用前仍需校準。
- 回報：確定性事實與建議分開，不使用模型猜測不存在的進步或每日練習。

這是辨識管線、提示、驗證與介面的改良，**沒有進行微調訓練，也沒有已測得的準確率提升百分比**。完整曲譜、复杂反覆跳轉、裝飾音和多聲部仍須老師核對。正式發佈前需以授權且校正的真實譜例比較舊/新結果。

`node tools/score-eval.cjs expected.json actual.json` 可比較音符序列和音符+時值編輯距離，另需人工評估減時線/連弓/指法等記號。訓練需另行取得資料使用同意、去識別化、保留獨立測試集；本次沒有上傳任何學生資料做訓練。
